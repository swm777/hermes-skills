# Hermes AI 投研技能库

自动化A股投研的完整AI技能集——从数据获取、估值建模、财报分析到缠论技术、供应链瓶颈挖掘、全自动量化管线。

## 📊 技能列表

| 技能 | 功能 | 数据源 |
|------|------|--------|
| **ths-data** | 同花顺+东财数据接口 | 同花顺/东财/mootdx |
| **awesome-finance** | A股每日情绪日报 | 同花顺板块+龙虎榜+涨停 |
| **model-builder** | DCF估值+敏感性+蒙特卡洛 | 东财财报+腾讯行情 |
| **earnings-reviewer** | 财报审阅+同比环比+异常标注 | 东财datacenter |
| **quant-trader** | 一人量化：mootdx→czsc→智囊团 | mootdx+czsc |
| **serenity-skill** | 供应链瓶颈分析（9步框架） | 公开信息+财报 |
| **serenity-unified** | 统一卡点投资框架v3.0 | 公开信息+财报 |
| **czsc-thinking** | 缠论技术分析思维 | czsc 0.10.12 |
